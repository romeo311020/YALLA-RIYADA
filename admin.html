    المباريات

    المباريات اليدوية

    أضف مباراة بنفسك (للمباريات اللي مش في الـ API أو لو الحصة خلصت). التشكيلة والملخص من قسم «التشكيلات والأحداث».

    ➕ إضافة / تعديل مباراة يدوية
    تجهيز مباراة احتياطية من الـ API

    اختر مباراة من القائمة لتنسخ أسماء الفريقين واللوجوهات والموعد، وبعدها أضف رابط المشغّل. المباراة اليدوية تظهر حتى لو الحد اليومي للـ API خلص.

    بيانات المباراة المحفوظة

    لا يوجد. اختر مباراة من القائمة أعلاه لحفظ التشكيلة والأحداث والإحصائيات مع المباراة.

    التفاصيل (تظهر في تبويب «التفاصيل»)

    استخدم رابط Embed رسميًا ومصرحًا به فقط.

    المباريات اليدوية

    API

    تعديل مباراة من الـ API

    تأجيل، إلغاء، تغيير النتيجة أو الموعد، وإضافة ملاحظة. اللي تسيبه فاضي بيفضل من الـ API.

    🛠️ تعديل مباراة API — تأجيل / إلغاء / نتيجة / ⭐ مباراة مهمة

    اختار اليوم ثم المباراة، وعدّل اللي محتاجه. اللي تسيبه فاضي هيفضل زي ما هو من الـ API. التعديل بيظهر للزوار في القائمة وصفحة المباراة.

    ⭐

    إضافة المباريات المهمة حسب التاريخ

    اختار تاريخ وعدد الأيام، حمّل المباريات، علّم اللي عايزه، واحفظها كلها مرة واحدة. بتفضل ظاهرة حتى لو الـ API خلص.

    المحفوظة حاليًا

    دي المباريات اللي اتحفظت كمهمة. الحذف بيشيل ⭐ والنسخة الاحتياطية.

    التشكيلة

    التشكيلات والأحداث

    اختار المباراة (يدوية أو من الـ API) وعدّل التشكيلة وملخص الأحداث. من غير الإحصائيات.

    ✍️ تشكيلة وملخص المباراة يدويًا (من غير الإحصائيات)

    اختار طريقة اللعب وهتظهر ١١ خانة، كل خانة مكتوب عليها المركز (حارس، ظهير أيمن، قلب دفاع…). اكتب رقم واسم اللاعب في مكانه، ورسم الملعب بيتعمل لوحده. الخانات الفاضية مش بتظهر.

      الفرق

      الفرق الأكثر متابعة (بتظهر مبارياتها الأول)

      مباريات الفرق دي هي اللي بتظهر في «⭐ مباريات مهمة» وبتتقدّم جوه كل بطولة. الترتيب من فوق لتحت حسب الشعبية.

        لو الفريق من بطولة مش في القائمة، اكتب اسمه بالإنجليزي زي ما بيظهر في الـ API عشان مبارياته تظهر (التعديل بيوصل للزوار خلال دقائق).
